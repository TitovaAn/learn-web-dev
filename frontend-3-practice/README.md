# Задание 3. Основы React — Страница «Выбор даты и времени»

Перевод страницы «Выбор даты и времени» для онлайн-записи в салон красоты «Линия» на React.
Вся функциональность из предыдущих заданий (HTML/CSS + нативный JavaScript) реализована в компонентном стиле.
